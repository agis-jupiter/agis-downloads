### Installation

1. Scan the QR code or open the download link on the Android device.
2. Open `AGIS-Android.apk` after it downloads.
3. If Android asks, allow installation from the browser or file manager being used.
4. Review the Android installation prompt and tap **Install**.

The APK must remain signed with the established AGIS signing certificate for Android to accept future releases as updates.
